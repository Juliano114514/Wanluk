# 韵录：单机方言采集助手

面向汉语方言田调。发音人使用引导模式自录，研究者在本机编辑调查包。通用题目与汉语音韵标注分离，为后续语言扩展保留空间。

当前代码接入了下述单机链路；录音、迁移和文件交换仍需按文末清单进行真机验收。未接入服务器、链接领取、账号、录音上传或云同步。

## 使用流程

1. 首页选择“开始录制”，再选择调查包；通过“扫一扫”或“从文件导入”接收方案。“管理员”入口用于调查包和字库管理。
2. 称呼与方言均为选填，默认记在本机、不重复询问；后续可在准备录制时修改，也可从“管理员 → 右上角齿轮 → 设置 → 录制者信息”修改。点击“开始录制”确认已了解用途并同意录制。
3. 录制页以无边框大字为主，字库单字题的已有组词提示居中显示；底部提供上一个、播放、录制、重新录制、下一个和“不会读，跳过”。正式录音及重录默认长按开始、松手停止，可在“管理员 → 设置 → 录音方式”切换为点击开始、再次点击停止。试音、进度、备注、历史与导出位于“更多”。
4. 从“开始录制 → 我的录制”继续；题目位置和已完成进度存入 Room。
5. 末项点击“结束”保存进度，显示已录／跳过／待录数量并询问是否导出，可选择“立即导出”或“稍后”。“我的录制”条目菜单也可导出成果 ZIP，未完成的录制同样支持；无有效录音时前置提示导出失败。文件写入系统文件选择器指定的位置，再自行转交研究者。

内置预设依次为：山村咏怀·20字（整篇1条）、日常用词·30词、斯瓦迪士核心词·100词、郭沫若没出息·约200字（逐句8条）、平水韵·东韵·392字和全量录制·约10291字。文段字数只统计正文汉字，字库数量按独立字目计算；东韵按字库“韻＝東”选取，保留声调、等第及同字不同音。

斯瓦迪士核心词保留“用你的方言怎么说？”提示、题目身份、每题录一次和允许跳过；题目使用 `ex_` 自定义内容，不加入内置汉字字库。中文提示按 [Concepticon 收录的 Swadesh-1971-100](https://github.com/concepticon/concepticon-data/blob/master/concepticondata/conceptlists/Swadesh-1971-100.tsv) 编号顺序整理，少量歧义通过题目补充说明澄清。

原“家乡话录制体验 · 30 项”以“日常用词·30词”保留内容，只演示工作流程，未经具体方言研究设计审定，不代表完整音韵覆盖。原有预设保持 packageId，以新版 revision 更新名称与分类和数量后缀；历史版本和录制快照保留。内置预设不能删除，编辑时先生成副本。

## 研究者的本地编辑

- “新建调查包”进入编辑器，选择字目／词汇／文段分类，再选字或添加自定义内容；字库多选仍可命名并保存方案，也提供三类选择。
- 方案分类独立于题型和单字／词语呈现方式，切换分类不改写题目。文段默认点击开始、再次点击停止；字目和词汇继续遵循现有录音方式设置。
- 管理页点条目进入编辑，复制、导出和单个删除放在条目“更多”；编辑页的说明、语言、方言、预览与 JSON 放在“更多”。
- 字库支持搜索、已选筛选、全选当前筛选和长按详情；摄、罕度、声母、韵、声调、等、呼、多音和收藏筛选可组合使用，选字时可切换单字／词语。详情可收藏或取消收藏，同字不同音的字目独立保留。
- 在调查包设置中统一指定单字／词语呈现、录制提示、每题 1–5 次重复和是否允许跳过。各题通过 ext_info 指定例外或补充说明，也可恢复继承。
- 添加自定义单字、词语或句子，调整顺序；修改内置字目的文字后成为 ex_ 自定义条目，只随方案与录制快照保存，不加入字库。
- 预览发音人提示，或通过高级 JSON 编辑器修改协议允许的字段。
- 保存生成新版本；已有录制会话使用完整任务快照，后续编辑不会改写旧任务。
- 相同 packageId / revision 按内容与继承设置比较，忽略设备本地题目实例 ID；一致时跳过重复，不一致时拒绝覆盖。

调查包和“我的录制”支持搜索；录制还可筛选“有待录题”和“待导出”。进度按每页 80 题读取，支持待录／已录／跳过筛选、按原题号跳转及全选整个筛选结果。历史版本可以单个删除；进度条目可单独清空本题录音，删除采用版本时恢复待录，不自动采用旧版本。

编辑器停顿 800ms 后自动保存本机草稿，离开或正常进入后台时立即尝试保存；显示等待、保存中、已保存或失败重试状态。离开时可保留或丢弃，列表“更多 → 本机草稿”可继续编辑或单独丢弃。正式保存成功后移除对应草稿。草稿分块存入 Room，不把整份调查包放入页面 Bundle；允许名称、语言标记或题目暂时留空，正式调查包仍须完整校验。强制终止前尚未落库的输入不能保证恢复。

各数据列表的“更多 → 多选”提供已选数量、全选、清空和退出。返回键先退出多选，切换列表清空选择；旋转屏幕保留当前列表的选择，消失的条目自动移出选择。

| 列表 | 批量操作 |
|---|---|
| 录制方案／调查包 | 导出 ZIP、复制、删除用户调查包；删除全部版本，已有录制快照保留 |
| 我的录制 | 导出一个成果 ZIP、删除录制和全部音频 |
| 字库 | 全选当前筛选、新建调查包、导出所选字目的方案；保留内置字库 |
| 编辑器题目 | 导出所选、复制、移除；只修改草稿，保存后生效 |
| 录制进度 | 导出所选步骤、清空全部历史录音并恢复待录；题目和备注保留 |
| 本条录音历史 | 导出所选成功录音、删除版本；删除采用版本后恢复待录，不自动采用旧版 |
| 导入预览 | 导入所选有效方案、移出预览；移出不影响本机已有调查包 |

删除录音与登记音频清理任务在同一个 Room 事务内提交，再清理对应文件。失败任务留在数据库，可从结果弹窗或列表“更多 → 重试音频清理”重试；启动时尝试一次，失败后保留重试入口。旧 SharedPreferences 清理记录迁入数据库后才移除。

方案最多 20000 字目，包含重复次数后最多 100000 个步骤，并受文件与快照大小上限约束。当前只支持文本题目，不支持图片、音频提示、脚本、条件分支或任意网络资源。

## CSV 生成调查包

列表“更多 → 保存 CSV 模板”保存 UTF-8 BOM 模板；“从 CSV 生成调查包”依次进行字段映射、逐行错误预览、选择有效行、生成可编辑草稿。最后在编辑器正式保存。CSV 不写入汉字字库，也不导入录音。

- 支持 UTF-8／BOM、逗号、双引号转义和引号内换行，最多 16 MiB、64 列、20000 行题目；列数不一致、引号损坏或超限时整体停止。
- 字段：`text`、`type`、`builtin_id`、`instruction`、`hide_instruction`、`repetitions`、`allow_skip`、`note`，以及 `sheng/hu/deng/yun/diao/she/zu`。常见中文表头自动映射，也可手动选择列；同一列不能映射到多个字段。
- 题型支持 `character/word/sentence` 或 单字／词语／句子；空值继承方案默认设置。布尔值支持 `true/false`、`1/0`、是／否，明确填写的 false 保留。每题重复 1–5 次，总步骤上限 100000。
- 空 `instruction` 表示继承；`hide_instruction=true` 明确隐藏。隐藏与非空提示同时填写属于行错误。空 `deng` 表示未定，非空只接受 1–4 或 一二三四。
- `builtin_id` 必须明确填写并匹配内置字目，声明的文字或音韵坐标冲突时报告行错误。未声明 ID 的行作为独立自定义题目，不按汉字猜测内置来源。
- 字段值错误可移出预览或取消选择，继续生成有效行草稿；重复行保留原顺序，自定义题目各有独立 ID。映射、选择和预览保存在当前 ViewModel，进程退出后重新选择文件。

## 界面约定

参考[不背单词](https://www.bbdc.cn/index)的文字层级与留白、[微信 WeUI](https://github.com/Tencent/weui)的分组列表，以及 [Material 的可访问性建议](https://developer.android.com/develop/ui/compose/accessibility/api-defaults)和字节 [Semi Design 的语义化 tokens](https://semi.design/zh-CN/basic/tokens)。

- 白灰中性色为主，绿色用于主要操作和选中状态；深色使用相同语义色角色。
- 列表和字目网格使用直角，主要页面边距 16dp；按钮 4dp、录音主按钮 8dp、弹窗 12dp 圆角。
- 操作控件保留至少 48dp 触控区域；窄屏或大字体下录制操作自动换行；设置、长按菜单、表单与提示采用简短标签。
- 启动图标内部图形居中缩小至 85%，保留背景；重新录制图标使用回转箭头和麦克风，SVG 与 Android VectorDrawable 同步维护。

## 方案交换协议 v2/v3 与本地快照

- 交换结构：[foundation/src/main/proto/survey_transfer.proto](foundation/src/main/proto/survey_transfer.proto)；契约与边界：[docs/survey-transfer-v2.md](docs/survey-transfer-v2.md)。
- 对外交换使用 Protobuf；内置字目只传固定 CSV ID，自定义条目携带 ex_ ID、文字、题型及可选标注。
- 每次导入严格匹配 WordCaseList.csv 原始字节的 SHA-256。设备数据库自增 ID、录制者资料与录音不进入方案交换。
- 本地方案和录制快照继续使用完整可读 JSON。schemaVersion 表示本地结构版本，packageId + revision 表示方案内容版本。
- itemId 是本地题目实例身份，wordId 是字目来源；同一内置字目可在不同位置重复出现。text、instruction 等字段保存本次实际录制内容。
- phonology 是可选的汉语音韵标注。其他语言或无传统音韵坐标的题目无需填写。
- recordingProfile 固定为 wav-pcm16-48000-mono，不支持静默改变采集预设。
- 新方案、草稿和录制快照采用本地 JSON v3，planType 必填，取值 character／word／passage；继续读取 v1/v2，旧方案不自动升级为文段。分类随 JSON、CSV 导入选择、分块快照和 Protobuf 交换保存，Room 表结构不变。
- 字目和词汇采用 Protobuf v2 并追加可选 plan_type；文段采用 v3，旧应用拒绝接收文段新版。更新后的内置预设 revision 也须使用支持该版本的韵录接收，旧版本预设仍可读取与交换。

保留本地 v1 方案与旧录制快照的读取能力；旧 JSON 文件及 WANLUK1 分片二维码不再作为外部交换入口，需要从应用重新导出。旧本地方案导出时，仅将文字、题型和标注完全匹配当前字表的字目转成引用，其余内容作为自定义条目保留。历史 v1 结构见 [docs/survey-package.schema.json](docs/survey-package.schema.json)，内置示例见 [starter-zh.json](foundation/src/main/assets/surveys/starter-zh.json)。

本地完整 JSON 与分块快照上限为 16 MiB；显式校验类型、长度、版本、ID 唯一性和总步骤数，拒绝重复字段、过深嵌套和不支持的字段。数据库 JSON 按有界片段读取；调查包列表使用持久化摘要，会话列表不读取 packageJson。录制页只订阅当前题目及其历史，每 100 字目的快照通过 itemId 定位；完整会话只在成果导出时读取。进度和字库每页 80 条，批量 ID 查询分为最多 900 个一组。

## 录音与恢复

- AudioRecord 采集 PCM，原始文件为 WAV / 48 kHz / 16-bit / 单声道。
- 检查设备对 UNPROCESSED 音源的支持；不支持时明确使用 VOICE_RECOGNITION，并记录实际选用音源与路由设备描述。
- 新录音（含试音）保存前按整段峰值施加统一线性增益，最多4倍，放大后峰值不超过29000/32768；原始峰值较高时保持1倍，静音不放大。不使用压缩、降噪或随时间变化的自动增益，不能改善信噪比。旧WAV不改写。`appliedGain`／CSV `applied_gain` 记录保存增益，旧录音为1；peak/rms为保存后数值，削波比例与提示仍反映采集信号。
- 不支持指定采样格式时明确报错，不静默降采样。实际设备处理行为和科研适用性需要实测。
- 字目和词汇单条最长120秒，只有文段分类最长600秒；试音仍为15秒。文段正文左对齐、可滚动，底部录音操作固定。录前空间门槛为 max(32 MiB, 最大WAV字节数 + 8 MiB余量)，到时自动保存。
- 长按录音在松手、手势取消或控件离开界面时请求停止；首次授权麦克风后需重新长按，不在授权回调中自动开始长按录音。试音仍通过明确点击开始，辅助功能也保留点击启停入口。
- 录制期间显示电平、保持屏幕唤醒；声音过小、可能削波、过短、设备路由变化会给出提示。这些提示不等于研究质量认证。
- 录音先写独立 .part 文件，完成 WAV 头和数据同步后才成为 .wav；数据库成功保存后才替换本条采用版本。
- 保留全部成功的重录版本，可回听并重新采用旧版本。每个已保存版本可标为未复核／通过／需重录；新版本默认未复核，采用旧版本保留其复核状态。
- 切后台会请求结束本条并保存；没有前台服务，不承诺锁屏或后台持续录音。
- 进程被杀后，未完成的录音尝试标为中断，不计入完成；上一次成功录音不变。中断 .part 文件及极端中断时的未关联文件可能留在应用目录，不作为有效音频导出。
- 备注可手动保存，在切换题目、离开会话、开始录音和正常退后台时也尝试保存；强制杀进程前未落库的编辑不能保证恢复。

## 两种导出文件

### 调查方案（二维码 / Protobuf / ZIP）

只包含字目引用、自定义内容、方案说明与录制规则。通过系统文件选择器保存二维码 PNG、.pb 方案文件或 ZIP，再主动打开系统分享面板。另一台装有相同内置字表的韵录设备可从“开始录制”或“管理员”页面导入。

管理员的调查包条目“更多 → 分享二维码”显示一个完整二维码；接收方从“扫一扫”扫描，或从文件识别收到的图片。导入前统一预览名称、字目数量、重复与冲突结果，再确认添加有效方案。

- Protobuf → GZIP → URL-safe Base64，字目／词汇前缀 WANLUK2，文段前缀 WANLUK3，M 纠错级别；最多 2331 ASCII 字节，并实际检查 ZXing 能否编码。超过单码容量时提示导出一个 ZIP，不再分片。
- 管理页支持批量导出 ZIP，最多 32 个独立方案。接收 ZIP 自动识别其中的 .pb 和新版二维码图片；重复方案跳过，冲突或无效条目逐项报告，不覆盖本机方案。
- SHA-256 校验负载完整性与字表一致性，不代表来源身份认证。交换负载最大 2 MiB，图片最大 12 MiB 并缩采样解码。
- ZIP 压缩输入最大 32 MiB、展开总量最大 64 MiB、最多 128 个条目；拒绝嵌套 ZIP、损坏目录及不支持的路径。容器损坏或资源超限时整体停止，不导入部分内容。
- 相机只在用户主动扫描时申请权限，也可直接选择文件。预览保存在当前 ViewModel；关闭导入或进程退出后需要重新选择。

### 录制成果包（ZIP）

| 文件 | 内容 |
|---|---|
| task.json | 本次录制的完整任务快照 |
| metadata.csv | 每个步骤、当前采用录音、录音参数、状态、备注和跳过原因 |
| session.json | 会话信息及所有录音尝试，包括未采用版本和中断状态 |
| audio/*.wav | 全部成功保存的录音，包括旧版本；导出不再次改变音频字节 |
| sha256.json | 导出音频文件的 SHA-256 |
| README.txt | 字段和使用说明 |

- 可导出尚未完成的任务，pending / skipped / recorded 分别表示待录、主动跳过、已有采用录音。
- 试音及中断片段不导出。音频文件使用会话 UUID 和录音 UUID 定位，不使用字词文本拼接本地路径。
- CSV 使用 UTF-8 BOM、标准字段转义，并对潜在表格公式文本加单引号；JSON 保留原文本。
- ZIP 流式写入所选文档。失败时不标记导出成功，本地原始录音保留；目标目录可能留下不完整文件，需要删除后重试。
- 导出包含发音人代号、方言背景、声音和备注。界面会确认范围，不自动上传或发送。

成果包 `exportSchemaVersion=3`，WAV 名称包含题号、内容、发音人、方言、重复次数与版本，例如 `0001_我_小王_东北话_第1次_版本1.wav`。文段使用标题和正文开头；内部UUID路径及WAV字节不变。`takes[].audioFile`、CSV和校验和使用同一实际相对路径；CSV原列与研究信息列保持，详见 [成果包 v2/v3 字段契约](docs/result-export-v2.md)。研究信息位于录制条目的“编辑信息 → 研究信息（选填）”，不进入对外方案交换。

会话内容变化时递增 contentRevision；位置切换不改变内容版本。完整 ZIP 写入并关闭成功后，仅在版本仍一致时登记已导出；所选步骤／历史导出不登记整条会话已导出。备注和资料保存不重新统计全部题目，已录／跳过／完成数在题目状态变更事务中增量更新。

单会话 ZIP 和批量包内部会话目录采用录制名称、发音人、方言、录制日期及短会话编号；批量 ZIP 标明录制组数与导出时间。根目录 `index.json` 关联会话ID和实际目录，不嵌套 ZIP。只有完整会话导出成功才更新该会话的导出状态。

进度列表导出保留原步骤编号与完整 `task.json`，只包含所选步骤及其成功录音历史，并通过 `selection.json` 标记范围（JSON position 从 0 开始，CSV 显示题号从 1 开始）。历史导出使用 `recordings.json`、`takes.csv`、`selection.json` 与所选 WAV，保留会话资料、所在步骤、采用标记和备注；只导出已保存版本。两种所选导出都不代表整条会话完成。

当前成果包用于人工交接与 Praat 分析，不提供成果 ZIP 自动恢复到另一台韵录的功能。

## 字库与数据迁移

当前内置 WordCaseList.csv 为 UTF-8 BOM、13 列、10292 个数据行。其中来源 ID 6357 没有字目，导入时跳过，因此有效条目为 10291；有组词的行数为 8754。

表头：id,聲,呼,等,韻,調,組,攝,單字,多音,组词,原註,罕度

- 续行继承上一条音韵坐标；同字不同读音或义项保留独立记录。
- 内置资产按 SHA-256 检查更新，不再使用“数量不同就清空重导”。
- 稳定来源 ID 采用 builtin:wordcase:<CSV id>；维护 CSV 时不得重排或复用已有来源 ID。
- v2 升级时按完整内容匹配旧记录，保留其数据库 ID；相同内容的多条记录逐条匹配。
- 字库更新在事务内完成，按来源 ID 更新或新增，保留用户条目和未匹配的旧条目，不主动清理旧字。
- 多音列 1／0 分别存为 true／false，未标注保留 null。来源映射版本独立于资产 SHA，升级旧数据库时补齐多音标记；原 CSV 字节和交换哈希不变。收藏按稳定 sourceId 保存，无来源的旧条目使用隔离的本机 ID 命名空间。
- 等的空白或 - 在旧字库中仍保留原有 0 语义；生成任务标注时转换为 null，不伪造音韵分类。
- Room v3 增加调查包、会话、步骤、录音和内置资产版本表，v4 增加会话快照分块，v5 增加摘要、计数、内容／导出版本、复核、研究字段、题目定位、清理任务、分块草稿及收藏，v6 增加录音保存增益；保留 v1→v2→v3→v4→v5→v6 迁移链，不破坏性重建或重编已有 ID。旧计数在迁移时回填，摘要在首次初始化时补齐，旧录音增益为1。
- 同名同音的条目不能按字符去重；调查任务持有题目快照，不依赖本地字库自增 ID。
